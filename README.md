# Оценка расстояния до поверхности по кадрам дрона

Проект содержит предварительный анализ двух записей полёта от 18 сентября 2025 года: кадров нижней камеры, телеметрии FC и измерений лидара.

## Что лежит в проекте

- [`report_for_supervisor.md`](report_for_supervisor.md) — короткое описание проделанной работы, вопросов и следующих шагов; его можно отправить научному руководителю.
- [`dataset_report.md`](dataset_report.md) — подробный отчёт по составу, частотам, синхронизации и ограничениям данных.
- `scripts/` — скрипты анализа датасета, сопоставления кадров с лидаром и аудита участка 04:12–04:13.
- `results/` — сводные таблицы и производные результаты аудита.
- `figures/` — графики и контактный лист кадров вокруг резких изменений `dist`.

**Целевая величина — `dist` из лидара, расстояние до поверхности под дроном.** `relative_alt` из FC оставлена только для сравнения. Лидар измеряет реальную величину с некоторой погрешностью; точная погрешность и смысл повторяющегося значения `0,1 м` пока не установлены.

Исходных датасетов в репозитории нет: оригинальные `fc_data.csv`, `lidar_data.csv` и фотографии остаются локально. В проекте лежат только скрипты, графики, сводки и производные таблицы аудита.

## Повторный запуск

Установите зависимости из [`requirements.txt`](requirements.txt). Положите исходные папки записей рядом с README, сохранив их имена:

```text
drone-distance-study/
├── 20250918_lidar/
├── 20250918_lidar_evening/
└── scripts/
```

Эти папки перечислены в `.gitignore` и не попадут в Git. Запускайте команды из корня проекта:

```powershell
python scripts/analyze_drone_dataset.py . --out results/eda
python scripts/audit_drone_target.py . --out results/target_audit
python scripts/audit_evening_focus.py
```

Скрипты проверяют частоту измерений, временное сопоставление, распределения и резкие изменения. Флаги скачков помогают найти участки для просмотра, но сами по себе не означают ошибку.

## Что ещё нужно уточнить

- Модель и настройки лидара, его паспортную точность и минимальный рабочий диапазон.
- Почему появляется `dist = 0,1 м`: это может быть измерение у поверхности или нижний предел датчика.
- Чем проверить точность `dist` независимо от FC: например, измерениями на известной высоте или контрольным измерителем.

Камера записывает только часть полётных журналов: в обеих сессиях её запись начинается позже и заканчивается раньше, чем журналы FC и лидара. Для обучения и проверки модели данные нужно делить по непрерывным временным отрезкам, а не случайно по соседним кадрам.
